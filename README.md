# 照常 · Loopling

每个人都应该专注**今天**最重要的事情，提前安排好**本周**的工作和生活；未来想做但当下还不能执行的事，先放进**计划**里。

一个纯静态的单页待办应用，没有后端，部署在 Vercel，数据保存在浏览器本地，可选通过 GitHub 私密 Gist 在多台设备之间同步。

## 功能

- **三个视图**：今天 / 本周 / 计划，底部悬浮毛玻璃导航
- **待办详情**：点击待办原地展开，可设置视图、优先级（P0–P4）、日期、提醒、子任务、备注
- **日期决定视图**：日期是今天放进今天，在本周内放进本周，更晚的放进计划；没有日期时以手动选择的视图为准
- **自动顺延**：今天没完成的事，过了零点自动移入本周
- **备注支持列表**：行首输入 `- ` 变无序列表，输入 `1- ` 或 `1. ` 变有序列表
- **排序**：有优先级的按 P0→P4 排在前面，同档内新添加的在最上面，也可以拖拽调整
- **完成**：撒花动画，自动收进「已完成」，子任务一起完成
- **深色 / 浅色**模式，可添加到手机主屏幕当作 App 使用

## 多设备同步（可选）

数据保存在你自己的 **私密 Gist** 里，不会写进这个仓库，所以同步不会触发重新部署。

1. 打开 GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token
2. Repository access 选 **Public repositories (read-only)** 即可（不需要访问任何仓库）
3. 在 **Account permissions** 里把 **Gists** 设为 **Read and write**，其余保持默认
4. 生成后复制 Token，在网页右上角点击同步按钮，粘贴并「连接并同步」
5. 第一次连接会自动创建一个私密 Gist；其他设备填入同一个 Token 会自动找到它

同步规则：每条待办单独记录修改时间，多台设备的修改按条目合并，后改的生效；删除也会同步。页面打开、切回前台、每分钟以及每次修改后约 1.5 秒都会自动同步。

> Token 只保存在当前设备的浏览器里。建议只授予 Gist 权限，并设置一个过期时间。

## 部署

纯静态文件，直接在 Vercel 导入这个仓库即可，无需任何构建配置。每次推送到 `main` 分支会自动重新部署。

## 文件

- `index.html`：整个应用（HTML + CSS + JS）
- `fonts/`：Geist、Geist Mono（SIL OFL 1.1）。标题用的 MiSans、得意黑已按需子集化内嵌在页面里
- `icons/`、`manifest.webmanifest`：主屏图标和 PWA 配置
